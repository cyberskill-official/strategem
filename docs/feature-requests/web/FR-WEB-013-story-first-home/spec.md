# WEB-013

## Goal
Home tells a short human story (you have a question → see a map → decide) with visuals; assume zero Tam Thức knowledge.

## §1
1. Hero in everyday Vietnamese; no jargon in first screen.
2. Visual 3-step journey (icons + short lines).
3. One primary CTA dominant; secondary links quieter.
4. Systems introduced as metaphors (map / conversation / season), not only classical names.
5. FAQ collapsed by default; shorter pain cards.
