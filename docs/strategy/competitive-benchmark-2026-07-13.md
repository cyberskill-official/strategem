## 1. Luangiai.vn — deep profile

### 1.1 Positioning
- **Category:** Tử vi Đẩu Số + modern psychology framing.
- **Promise:** Free accurate chart (an sao) + paid **handcrafted / deep** life readings; “không văn mẫu”.
- **Tone:** Empathetic, conversational Vietnamese; problem–agitate–solve; heavy social proof.
- **Legal soft-sell:** FAQ says “not magic / apply advice yourself” — still sells destiny language more aggressively than Strategem’s heritage-education doctrine.

### 1.2 Business model
| Layer | Mechanic | Price signal (VND, observed 2026-07) |
|---|---|---|
| **Free hook** | Lập lá số online, no ads claim | 0 |
| **Sample** | Free topic sample by email | 0 → email capture |
| **Single SKU** | Chuyên sâu ~30 mục / Cao cấp ~100 mục | ~289k / ~489k |
| **Bundles** | 2–5 bài combos, themed (duyên, công danh, thời vận) | ~489k–1.689k |
| **Flagship promo** | “COMBO 3 bài 100 mục 789k (−50%)” sticky bar | 789k vs 1.467k |
| **Content SEO** | Tử Vi Toàn Thư (14 chính tinh, 60 hoa giáp, phụ tinh…) | Funnel → shop |
| **Community** | Messenger channel / “Người Gieo Duyên” | Retention + trust |
| **Checkout** | WooCommerce + OnePay/VNPay; account + password on form | Ownership |

**Monetization pattern:** *Tool free → emotional framing → tiered digital product → combo upsell → SEO + social proof loop.*

### 1.3 Feature map (sub-surfaces)
1. **Home form-first CTA** — name, DOB, birth hour (Tý sớm…Tý muộn), gender, package tier, topic, year, email, password → “Xem luận giải”.
2. **3-step funnel** — (1) free chart (2) free sample topic (3) paid full reading, lifetime storage claim.
3. **Topic products** — tình duyên, sự nghiệp/tài lộc, vận hạn, hôn nhân/gia đạo, sức khoẻ, tổng quan 2026.
4. **Landing per topic** (e.g. sự nghiệp) — pain cards, 100-point outline, dual pricing cards, FAQ, form again.
5. **Shop grid** — 32+ SKUs, sort by price/popularity, strike-through savings.
6. **Content hub** — encyclopedic star/year pages (SEO + authority).
7. **Testimonials carousel** — named initials + topic tag.
8. **FAQ accordion** — delivery 24–48h vs “1–2 phút algorithm” (messaging inconsistency = trust risk).
9. **Sticky promo banner** + Zalo/Messenger contact.

### 1.4 UI / UX patterns
| Pattern | Detail | Effect |
|---|---|---|
| **Sticky urgency bar** | Combo price always visible | Conversion |
| **Form as hero** | Convert before scroll | High intent capture |
| **Pain personas** | “Vòng lặp bế tắc”, “Ngã rẽ”, “Bên ngoài ổn / trong bất an” | Emotional identification |
| **Us-vs-them table** | Online rập khuôn vs Luangiai cá nhân hóa | Differentiation |
| **Numbered prestige** | “100 điểm chạm”, “250,000+ bản luận” | Authority |
| **Warm imagery** | Soft photos, community | Soft luxury |
| **Mobile-first commerce** | Cart, add-to-cart, Zalo float | VN habit |
| **Mixed auto/manual claim** | Handcrafted vs 1–2 min algorithm | Risk if audited |

**Visual:** WordPress/WooCommerce, cream/warm pages, product cards with “GIẢM GIÁ”, serif/display headlines, long-scroll landings.

## 2. tamlyhocvn.club — deep profile

### 2.1 What the live site is
Primary page title/content: **“Thư viện Kịch bản Sales”** with **Zalo CTA** (`0377 418 438`).  
This is **not** a public multi-quiz MBTI portal; it is a **sales-enablement / psychology-for-conversion** product surface (scripts library + consult).

### 2.2 Related viral cluster: tamlyhocvn.com (VCP)
Same brand ecosystem / market expectation users associate with “tâm lý học VN”:
- **Services:** therapy/counseling, psychology courses, special-needs assessment.
- **Content:** CBT, EFT, mindfulness, soft skills articles.
- **Conversion:** Zalo float, course registration, account login, trust via student feedback images.

### 2.3 Business model (club + cluster)
| Layer | Mechanic |
|---|---|
| **Lead magnet** | Free knowledge / scripts access tease |
| **Consult** | Zalo human sales (high-touch VN) |
| **Courses & therapy** | B2C paid education / clinical (on .com) |
| **Community trust** | Testimonials, professional institute framing |

**Monetization pattern:** *Content authority + Zalo high-touch + courses/services* — less SKU shop, more **relationship selling**.

### 2.4 UI / UX patterns to note
- Minimal club page → **single clear CTA** (Zalo).
- Institute site: **service cards 3-up**, content grid, sticky Zalo, login.
- Language: professional, caring, clinical-educational (not destiny).
- Viral psychology products in VN generally use: **free quiz → typed result share card → upsell course/consult**.

## 4. Critique of Strategem

### Strengths (keep)
1. **Real engines** — reproducible ban; competitors often hide accuracy.
2. **Doctrine** — heritage education, AI disclosure, human review — stronger ethics than Luangiai’s mixed “1–2 phút algorithm / handcrafted” story.
3. **Three systems + learning path** — product depth.
4. **CyberSkill visual anchors** — brandable.

### Gaps vs viral monetizers
1. **No freemium ladder** — free cast has no paid “next step” product story.
2. **Home is product-correct, not desire-correct** — missing pain personas, social proof, FAQ, packages.
3. **Copy too institutional** — underuses empathetic “ngã rẽ / gỡ bế tắc / thấu hiểu” while staying non-superstitious.
4. **No pricing page** — cannot monetize what users cannot buy.
5. **No shareable outcome card** — psychology sites go viral via shareable types; we need shareable “board snapshot + insight teaser”.
6. **Weak continuous curiosity loops** — Luangiai has encyclopedia + year content; we stop at short learn lessons.
7. **No high-touch CTA** — VN conversion expects Zalo/consult for premium.
8. **Results end cold** — after chart, no “unlock full reading / timing pack” module.

### What NOT to copy
- Destiny guarantee language, fear-based “sai thời phá sản” scare.
- Fake “250,000+” without evidence.
- Manual-vs-auto contradiction.
- Dark-pattern sticky spam that breaks brand dignity.

## 5. Learnings → product decisions

| # | Learning | Strategem adaptation | Risk control |
|---|---|---|---|
| L1 | Form/hero conversion | Rewrite home as conversion landing | Keep educational positioning |
| L2 | Free → paid ladder | Free cast + sample insight; premium packages UX | Packages can be “coming soon” + waitlist until payments |
| L3 | Topic packaging | Map to Timing / Host–guest / Career-style packs | Use decision-support names, not fate |
| L4 | Pain personas | 3 cards on home | No medical/legal/finance claims |
| L5 | Us-vs-them | “Generic online tools vs Strategem” | Fact-based (deterministic, cited, review) |
| L6 | Social proof shell | Testimonial slots + structure | Placeholder honest labels until real quotes |
| L7 | FAQ trust | Monetization FAQ | Align with LEGAL-001 |
| L8 | Sticky soft CTA | Fixed “Lập quẻ / Gói cao cấp” bar | No false urgency |
| L9 | Share card | Results share teaser | No PII in URL |
| L10 | Zalo-style contact | Optional contact strip | Config via env later |
