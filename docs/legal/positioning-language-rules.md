# Positioning language rules (TASK-LEGAL-001)

Product posture: **heritage education and decision support**, never fortune-telling.

## Forbidden categories

1. Certain-future assertion ("you will definitely…", "chắc chắn sẽ…")
2. Medical advice under a divination guise
3. Legal / financial advice under a divination guise
4. Fear / dependency language that traps users

## Do

- Frame as classical analysis + optional timing windows
- Require AI disclosure + citations
- Use keys from `copy-deck/copy-keys.yaml` for all legal-facing UI strings
